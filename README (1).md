# Thesis Lab

A Finance & Investing simulation for John Hersey High School. Students pick one of six investor theses (Value Hunter, Growth Builder, Dividend Income, Momentum Trader, Macro Rotator, Capital Preserver), trade through a fictitious market year, and are graded on how consistently each trade follows their thesis.

## How it works
- Single file: `index.html`. No build step, no server, no student login.
- Student work saves in the browser (localStorage). Students get a turn-in code to submit or to move to another computer.
- Rounds open with codes the teacher writes on the board.

## Files
- `index.html`: the whole app
- `vercel.json`: Vercel settings
- `README.md`: this file

## Hosting on Vercel
Import this repository in Vercel, set Framework Preset to **Other**, leave the build settings blank, and deploy.
